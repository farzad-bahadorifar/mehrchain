Download **mehrchain-release.apk** below and install it alongside the older
MehrChain preview. Keep RC3 installed to preserve its local-only habits.
Sign in separately in 1.0.0 to access habits already synced to your account.
The previous session and unsynced habits stay in the old app.

- Android 1.0.0 uses the permanent package ID `com.mehrchain.mobile`.
- Sign-in and signup show clearer feedback when the API is temporarily unavailable.
- Show Up lists completed steps. Connect is where you manage your connections.
- The updated Color Studio uses the app's palette and components.
- Future stable APKs can update 1.0.0 in place using the same signing identity.

Email verification delivery remains unavailable until the sender domain is
verified. The release assets include the SHA-256 checksum and signing manifest.
