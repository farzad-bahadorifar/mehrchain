# Historical source preservation

Current developer guidance and application copy are English. The files in
`original-language-records-2026-10-29.zip` preserve exact original bytes before
the English-only documentation migration. They are audit evidence, not alternate
developer instructions or an executable backlog.

The [SHA-256 manifest](original-language-records-2026-10-29.manifest.json) identifies
each original project-relative entry. In particular, the original approved V0.2
artifact hash is `0fe5e8d4def6a5254de500160a8cd8e06268c013f09a39b917b55916c04dca2a`.
English review presentations may have a different file hash because their review
labels were translated; that does not represent a new product design approval.

[contributing](../../CONTRIBUTING.md), [decisions](../roadmap/context.md).
