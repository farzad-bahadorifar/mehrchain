🛡️ Security & Delivery Verification

Open-Redirect Mitigation: auth.service.ts method pendingInviteReturnUrl() strictly enforces that returnUrl must start with /chain?, have single segment chain, and possess non-empty invite query param. External domains (e.g. //evil.com) or unauthorized internal paths are safely dropped to /dashboard.

Android APK Reality: AndroidManifest.xml currently contains only android.intent.action.MAIN. External web links will open in the system browser, not the installed APK, until custom App Links (assetlinks.json) or intent filters are implemented.
